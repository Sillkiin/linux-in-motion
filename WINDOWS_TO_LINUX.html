Linux после Windows: привычные действия

Эта памятка дополняет анимацию. На телефоне читаешь и проходишь тренажёр, а настоящие серверные команды вводишь на компьютере. Адреса и имена ниже — учебные примеры.

1. Где выполняется команда

Окно может находиться в Windows, а команда выполняться на Ubuntu. После входа через SSH — защищённое подключение к другому компьютеру — смотри на приглашение перед курсором:

Что видишь Где работаешь
PS C:\Users\...> PowerShell на Windows
adminuser@ubuntu-srv:~$ Командная строка Ubuntu
ubuntu-srv login: Ubuntu спрашивает имя пользователя; команды пока вводить нельзя
Password: Запрос пароля; вводимые символы обычно скрыты

adminuser@ubuntu-srv:~$ уже нарисовано системой. Когда в инструкции написано whoami, вводи только whoami.

2. Как подключиться с Windows

На Ubuntu сначала должна быть включена служба OpenSSH — программа, принимающая подключения. Компьютеры должны видеть друг друга по сети.

В PowerShell или Windows Terminal на Windows:

ssh adminuser@192.168.1.50

Замени логин и адрес на свои. При первом подключении проверь, что это нужный сервер, прежде чем подтвердить его ключ. Дальше используй свой пароль или настроенный ключ. Для выхода из подключения введи exit. Ubuntu продолжит работать.

3. Как копировать и вставлять

В Windows Terminal со стандартными настройками: выделить текст и Ctrl+Shift+C — копировать; Ctrl+Shift+V — вставить. Ctrl+V тоже может быть назначен на вставку. В других окнах и настройках сочетания отличаются.

Когда ничего не выделено, Ctrl+C обычно прерывает работающую команду. Поэтому это сочетание не стоит использовать наугад как копирование. Чёрная текстовая консоль VMware может не принимать обычный общий буфер Windows: для работы удобнее SSH.

В Safari на iPhone текст выделяют долгим нажатием. В учебном терминале можно нажать готовую команду под полем, затем «Выполнить».

4. Почему пароль не видно

Текстовый вход Ubuntu обычно не показывает ни буквы, ни звёздочки. Вводи пароль и нажимай Enter. Отсутствие видимых символов само по себе не означает ошибку.

Если вход не удался, начни снова с логина. Проверь раскладку, Caps Lock и отсутствие лишнего пробела или переноса строки при вставке. В учебную страницу настоящий пароль вводить не нужно.

5. Как выйти из программы

Где находишься Что обычно делать
Долгая команда, например ping Ctrl+C
Просмотр текста через less q
Редактор nano Ctrl+O, Enter — сохранить; Ctrl+X — выйти
Подключение SSH exit
Ввод захвачен VMware Ctrl+Alt возвращает управление Windows

6. Вместо букв дисков — дерево папок

В Linux всё дерево начинается с /. Личная папка обычного пользователя может быть /home/adminuser; сокращение ~ указывает домашнюю папку текущего пользователя. Папки с настройками обычно находятся в /etc, журналы программ — в /var/log.

Разделитель пути — /. Имена Report.txt и report.txt различаются. Скрытые имена начинаются с точки, например .bashrc. Папки Windows автоматически не превращаются в папки отдельной Ubuntu.

whoami
pwd
ls -lah
cd /var/log
pwd

whoami — кто я; pwd — текущая папка; ls -lah — её содержимое, включая скрытые имена; cd — перейти в другую папку. При успешном переходе cd обычно ничего не печатает.

7. Установка программ и права администратора

В Ubuntu программы обычно устанавливают через APT. Оно получает подготовленные пакеты из хранилища программ.

sudo apt update
sudo apt upgrade

Первая команда обновляет список доступного, вторая предлагает обновить установленные программы. sudo запускает разрешённое действие с правами администратора; обычно спрашивает пароль текущего пользователя.

8. Программа-служба и открытый сайт

Служба работает в фоне. Закрытие SSH-окна обычно не останавливает системную службу. Проверить Nginx — программу, выдающую страницы сайта — можно командой:

systemctl status nginx --no-pager

active (running) означает, что служба запущена. Доступность сайта с другого устройства проверяется отдельно: важны адрес, сеть и правила доступа.
