Слова из инструкции — простыми словами

Это справочник для первого знакомства с Linux. Не нужно заучивать весь список: заглядывай, когда встретишь непонятное слово. Названия программ сохранены, чтобы их можно было узнать на экране; рядом объяснено, что они делают.

Компьютер и установка

  • Сервер — компьютер или программа, которая выполняет работу для других устройств. Например, хранит общие файлы или отправляет страницы сайта. В нашем примере сервер — отдельный компьютер с Ubuntu.
  • Ubuntu — готовая операционная система на основе Linux. Она занимает на компьютере ту же роль, что Windows: запускает программы и управляет оборудованием.
  • Linux — название ядра, главной части системы, которая управляет памятью, процессами и устройствами. В разговоре так часто называют целые системы на его основе.
  • Дистрибутив — готовый набор из ядра Linux, программ и средств установки/обновления. Ubuntu, Debian и РЕД ОС — разные такие наборы, а не просто разные темы оформления.
  • Ubuntu Server — вариант Ubuntu для серверных задач. По умолчанию у него нет привычного рабочего стола с окнами. Это не означает, что весь Linux работает только в чёрном экране.
  • Виртуальная машина, ВМ — отдельный программный компьютер внутри настоящего. У него свой виртуальный диск и своя ОС. VMware — программа Windows, в которой сейчас работает наша учебная Ubuntu.
  • Физический компьютер — настоящая отдельная машина с процессором, памятью и диском. Если установить Ubuntu на неё напрямую, VMware для её работы не требуется.
  • SSD — накопитель, на котором хранятся система и файлы даже после выключения. По назначению это диск, как C: в Windows, но C: — буква раздела, а не модель самого устройства.
  • Оперативная память, ОЗУ, RAM — рабочее пространство запущенных программ. Содержимое обычно теряется при выключении; это не место постоянного хранения файлов.
  • ISO — файл с содержимым установочного диска. Его специальной программой записывают на флешку, чтобы запустить установку.
  • Образ — сохранённое содержимое диска или системы. Установочный ISO и готовый диск ВМ — разные виды образов, их используют по-разному.
  • Rufus — программа Windows для подготовки загрузочной флешки. Она записывает выбранный образ и заменяет данные на выбранной флешке.
  • Загрузочная флешка — флешка, с которой компьютер способен начать работу ещё до запуска установленной Windows или Ubuntu.
  • UEFI / BIOS — встроенная программа компьютера, которая начинает работать первой после включения, проверяет оборудование и выбирает, откуда загружаться. UEFI — современный вариант, BIOS — более старый.
  • Boot Menu — меню выбора загрузки на один запуск: например, начать работу с USB, а не с SSD.
  • Загрузчик, GRUB — небольшая программа, которая запускает установленную ОС. GRUB — название загрузчика, используемого в обычной Ubuntu. Само это слово не нужно вводить как команду при установке.
  • LTS — выпуск с длительной поддержкой. Пока действует соответствующая поддержка, производитель выпускает обновления по её условиям. Это не обещание бессрочной поддержки каждого приложения.
  • amd64 / ARM64 — разные семейства процессоров, для которых собраны программы. Для обычного 64-битного компьютера с Intel или AMD обычно нужен amd64; ARM64 — для другого оборудования.
  • Драйвер — часть программного обеспечения, которая позволяет ОС работать с конкретным устройством: сетью, дисковым контроллером и т. п.

Диск и файлы

  • Раздел диска — выделенная часть накопителя. Один SSD может содержать несколько разделов.
  • Разметка — создание и распределение этих разделов.
  • Форматирование — подготовка раздела для хранения файлов с созданием файловой системы. Оно может уничтожить прежние данные, поэтому выбор диска проверяют до подтверждения.
  • Файловая система — правила хранения файлов, папок, имён и прав на разделе. NTFS — знакомый пример Windows, ext4 — распространённый пример Linux. Просто копировать название из чужого примера вместо выбора своего диска нельзя.
  • Папка / каталог — два названия одного понятия.
  • Путь — адрес файла или папки в дереве каталогов, например /home/adminuser/note.txt.
  • Корень / — верхняя точка дерева файлов Linux, от которой начинаются абсолютные пути. Это не пользователь root.
  • Монтирование — подключение диска или раздела в определённое место дерева папок. Точка монтирования — это место, например / или /boot/efi.
  • EFI-раздел — небольшой раздел, где UEFI находит файлы для запуска ОС. Его обычно готовит установщик.
  • LVM — дополнительный способ распределять место на дисках между томами, то есть областями хранения. Полезен для гибкой настройки; для первого опыта можно выбрать обычные разделы без него.
  • Шифрование / LUKS — защита содержимого диска с помощью ключа. LUKS — один из способов организовать такую защиту в Linux. В простой установке при включении шифрования понадобится пароль разблокировки на каждой загрузке.
  • RAID — объединение нескольких дисков по определённой схеме, например для сохранения работы при отказе одного из них. Возможности зависят от схемы; отдельную резервную копию RAID не заменяет.
  • Резервная копия — сохранённая отдельно копия нужных данных, из которой можно восстановиться. Её полезность проверяют попыткой восстановления.
  • Снимок, snapshot — сохранённая точка состояния ВМ или данных для отката. Если он хранится рядом с оригиналом на том же диске, отказ этого диска может уничтожить и оригинал, и снимок.

Сеть и подключение

  • Локальная сеть, LAN — сеть дома или организации, в которой устройства могут обмениваться данными. Простой пример: Windows-компьютер и сервер подключены к одному домашнему роутеру.
  • Ethernet — обычное проводное сетевое подключение через кабель и сетевой разъём.
  • Роутер, маршрутизатор — устройство, которое соединяет сети. Дома оно часто также раздаёт адреса устройствам и подключает их к Интернету.
  • Сетевой интерфейс — сетевое подключение, которое видит ОС. Например, проводной адаптер с именем enp3s0. Имена могут отличаться между компьютерами.
  • IP-адрес — адрес устройства в сети, например 192.168.1.50. Для подключения нужно знать фактический адрес своего сервера.
  • Маска, префикс /24 — описание границ подсети: по нему система определяет, какие адреса доступны напрямую в этой сети. Это не номер порта.
  • Шлюз — устройство, которому компьютер передаёт трафик для других сетей. Дома шлюзом часто служит роутер.
  • DNS — служба поиска адресов по именам. Например, помогает получить IP-адрес для имени ubuntu.com.
  • DHCP — автоматическая выдача сетевых настроек. Сервер получает адрес, шлюз и DNS от роутера или другого устройства, которое их раздаёт.
  • MAC-адрес — идентификатор сетевого адаптера. Роутер может использовать его, чтобы закрепить за конкретным устройством один IP-адрес. Это не пароль и не учётная запись Apple.
  • Резервирование DHCP — правило на роутере: этому адаптеру каждый раз выдавать выбранный адрес.
  • Статический адрес — адрес, который задан в настройках компьютера вручную. Его выбирают с учётом всей сети, чтобы не занять чужой.
  • Netplan — средство настройки сети в Ubuntu. Оно читает текстовые файлы и передаёт настройки сетевым компонентам системы.
  • YAML — формат записи настроек с полями и отступами. Это не отдельная программа для Интернета. Неправильные отступы могут изменить смысл настройки или вызвать ошибку.
  • Прокси — промежуточный сервер, через который приложение отправляет сетевые запросы. Он нужен только там, где такой способ доступа действительно используется.
  • Порт — номер сетевого входа программы. IP указывает компьютер, порт — службу на нём: SSH обычно использует 22, обычный сайт по HTTP — 80.
  • TCP — один из способов передачи данных по сети. SSH и обычный HTTP используют TCP; запись 22/tcp в правиле означает соответствующий сетевой вход SSH.
  • SSH — защищённый способ подключиться к командной строке другого компьютера. После подключения окно остаётся на Windows, а команды выполняет Ubuntu.
  • OpenSSH Server — программа на Ubuntu, которая принимает SSH-подключения. Клиент SSH — программа на Windows, которая подключается к ней.
  • SCP — способ передать файлы между компьютерами через SSH. Он отличается от вставки текста в терминал.
  • SSH-ключ — средство входа, состоящее из двух связанных частей: закрытая остаётся у тебя, открытая добавляется на сервер. Закрытый ключ не публикуют и не копируют на сервер ради обычного входа.
  • Туннель SSH — перенаправление выбранного сетевого соединения через SSH. В нашей ВМ оно позволяло браузеру Windows открыть сайт Linux через локальный порт Windows.
  • localhost, 127.0.0.1 — сам компьютер, на котором сейчас работает программа. У Windows и отдельной Ubuntu это разные компьютеры.
  • NAT — преобразование сетевых адресов при передаче трафика между сетями. В VMware это позволяет гостевой Ubuntu выходить наружу через виртуальную сеть; отдельный физический сервер не обязан повторять её настройку.
  • Firewall, межсетевой экран — правила разрешения и запрета сетевых соединений. Это похоже на брандмауэр Windows.
  • UFW — программа для удобного управления такими правилами в Ubuntu.
  • HTTP / HTTPS — способы обмена запросами и ответами между браузером и сайтом; HTTPS использует шифрование соединения. Наличие шифрования не означает, что любой сайт заслуживает доверия.
  • NTP — способ автоматически сверять часы компьютера с сервером времени. Часовой пояс отдельно определяет, как показывать местное время.

Программы, команды и права

  • Терминал / консоль — место, где видны текстовые команды и их ответы. В разных окнах отличаются сочетания копирования и вставки.
  • Оболочка, Bash — программа, которая читает твою команду, понимает её запись и запускает нужное действие. Bash — название оболочки, используемой в нашей Ubuntu.
  • Приглашение команд — строка вроде adminuser@ubuntu-srv:~$. Она показывает, что оболочка ждёт ввод. Копировать её вместе с командой не надо.
  • Пакет — подготовленный для установки набор файлов программы с необходимыми сведениями о ней.
  • Зависимости — дополнительные программы и библиотеки, которые нужны выбранной программе для работы. Обычно их подбирает пакетный менеджер.
  • Менеджер пакетов, APT — средство, которое скачивает, устанавливает и обновляет пакеты. apt — команда управления им в Ubuntu.
  • Репозиторий — источник пакетов. В нём система ищет доступные программы и обновления.
  • Зеркало — другой сервер с копией пакетов из такого источника; его выбирают по доступности и другим условиям.
  • Snap — ещё один способ поставки и установки приложений в Ubuntu. Для первого опыта не обязательно выбирать дополнительные snap-приложения в установщике.
  • Конфигурация — настройки программы; часто это текстовый файл. Слово «настроить конфиг» означает изменить эти настройки, а не установить новую ОС.
  • Процесс — запущенная программа. Её числовой идентификатор называется PID.
  • Служба, сервис — программа, которую система запускает и обслуживает в фоне, например SSH или веб-сервер. Похоже на службы Windows.
  • systemd — часть системы, которая, в частности, запускает и останавливает службы. systemctl — команда для управления ими и проверки состояния.
  • Журнал, лог — записи о работе программы: запуск, запросы, предупреждения и ошибки. Он нужен для выяснения причин проблемы.
  • journalctl — команда чтения системного журнала systemd.
  • sudo — запуск отдельной команды с административными правами. В нашей Ubuntu запрашивает пароль текущего пользователя с такими правами.
  • root — пользователь с полными административными правами. Это не то же самое, что каталог /.
  • Nginx — название программы, произносится примерно «энджин-икс». В нашем примере она принимает запрос браузера и отправляет страницу сайта. «Веб-сервер» — описание её роли. Слово engine само по себе по-английски значит «движок», то есть основная часть какой-то программы; это не универсальная команда Linux. Написание команды установки — nginx.
  • curl — программа для обращения к сетевым адресам из терминала. Командой curl -I ... мы просим показать служебную информацию ответа сайта без самой страницы.
  • nano — простой текстовый редактор в терминале. Сохранение: Ctrl+O, затем Enter; выход: Ctrl+X.
  • less — программа для просмотра длинного текста без редактирования. Выход — английская клавиша q.

Пример: что означает одна команда

sudo apt install nginx

Читается так: «С административными правами установи программу Nginx через средство установки программ Ubuntu».

sudo — разрешение на административное действие; apt — средство установки; install — действие «установить»; nginx — имя программы. После установки можно отдельно проверить, запущена ли программа и отвечает ли сайт. «Установить», «запустить» и «настроить автозапуск» — три разных действия.
