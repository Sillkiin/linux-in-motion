# Linux в движении

Интерактивный учебник Ubuntu для начинающего пользователя Windows. Адаптирован под iPhone и другие телефоны.

- 25 сцен с анимацией, пояснениями и увеличением схем.
- 7 блоков, 21 вопрос с подсказками и повторными попытками.
- Учебный терминал, задания и результаты в браузере.
- Крупные кнопки, меню уроков, портретный и горизонтальный режимы.
- Подробная установка с иллюстрациями и словарь.

Открыть сайт: https://sillkiin.github.io/linux-in-motion/

Это статический сайт. Запускать сервер Ubuntu и устанавливать приложение для просмотра не нужно. Команды терминала разыгрываются внутри страницы. Настоящие пароли вводить не следует.

Главный файл — index.html. GitHub Pages публикует корень ветки main. Изменения в main обновляют сайт.

Озвучивание зависит от русского голоса на устройстве. Результаты сохраняются в браузере на этом адресе; результаты с локального файла или другого устройства автоматически не переносятся.

## Иллюстрации и источники

Собственные схемы устройств и шагов созданы специально для учебника. Справочные снимки установщика Canonical взяты из официальной документации; источники и условия CC BY-SA 4.0 указаны в UBUNTU_FROM_ZERO.html. Изменения для мобильного сайта: уменьшение размера и перекодирование в WebP.

Репозиторий содержит только учебный сайт. Диски виртуальной машины, пароли, SSH-ключи и локальные сценарии подключения в него не входят.
